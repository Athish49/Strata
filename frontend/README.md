# Strata frontend

Regulatory-change impact UI for Strata (Next.js 16 App Router, React 19, TypeScript, Tailwind v4, shadcn-style components on Radix).
This folder is a **standalone project and the deploy root**. Nothing in it imports from outside `frontend/`.
The app always reads live data from the FastAPI backend at `BACKEND_URL` (set in `.env.local`; the build fails if it is missing); if the backend is unreachable, pages show an error rather than sample data. The API contract is `../development_docs/ui_wiring_contract.md`. See `.env.example`.

## Run

```bash
pnpm install
pnpm exec next typegen   # once on a clean checkout, before typecheck
pnpm dev            # http://localhost:3000  (/ redirects to /app)
```

## Check

```bash
pnpm lint
pnpm typecheck
pnpm test           # vitest: labels, sentences, status, HTTP adapters, fixture invariants (tests use an in-memory test double)
pnpm build
pnpm test:e2e       # playwright (uses /opt/pw-browsers/chromium; never run `playwright install`)
```

## Deploy (Vercel)

Import the repository and set **Root Directory = `frontend`**. Set `BACKEND_URL=<backend url>` in the project's environment variables (build-time, so redeploy after changing it), and set `FRONTEND_URL=<this site's url>` on the backend so CORS allows it.

## Layout

- `app/app/**` the product (`/app/*`); `app/page.tsx` redirects to `/app` (marketing page deferred).
- `components/{ui,shell,engine,documents,kb,common}` UI. `lib/api/schemas` is the zod contract; `lib/api/client.ts` is the `StrataApi` interface; `lib/api/http/` is its only implementation.
- `lib/{labels,sentences,status,verticals,future-features}.ts` display strings, derivations and the disabled future-cue registry (spec §18).
- `fixtures/` and `tests/support/mock-api/` are test-only data and an in-memory test double; the app never imports them.
- `fixtures/` committed data. `scripts/build-fixtures.ts` regenerates company fixtures by reading `../backend/app/company/corpus` read-only (dev machine only; never part of build or CI). Engine fixtures are generated by `scripts/build-engine-*-fixtures.ts`.
- `FIXTURES_LAYOUT.md` fixture file map.

Design reference and spec live in `../frontend_development_docs/` (spec §17 for the visual system).
